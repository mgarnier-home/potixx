    - 7 = Je correspond au nombre de jours dans une semaine

    - 2eme indice : L'équipage que l'on ne choisit pas toujours, mais que l'on garde toute sa vie.
    - 3eme indice : rébus Fa(musique) + 1000(nombre)
  - 3 eme énigme : Mots croisés
    - Mot à découvrir : "agrandira"
      - A : Marraine
      - G : Grand-mère
      - R : Frere
      - A : Tata
      - N : Oncle

      - I : Cousin
      - R : Soeur
      - A : Amis

      - Bébé
